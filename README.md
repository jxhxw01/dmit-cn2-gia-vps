## FAQ

**便宜CN2 GIA VPS和普通VPS差别大吗？**

对电信用户差别最明显。普通163网络晚高峰丢包率能到30%以上，CN2 GIA走独立通道，高峰期受影响小。联通和移动用户的体感差别小一些；搬瓦工GIA-E回程走CN2 GIA、CMIN2和联通Premium，DMIT洛杉矶Pro的联通Premium和CMIN2只走接入方向，回程以官方状态页为准。

**10Mbps、15Mbps实际下载多少？**

丽萨基础版15Mbps，实际下载约1.5到2MB/s；精简版10Mbps再低一档。DMIT的MINI超流量后限速8Mbps，约1MB/s。跑轻量网站、API、代理中转够用，传大文件会等。

**年付中途能退吗？**

DMIT新订单3天内、流量不超过30GB全额退；30天内部分退；超过30天不退。丽萨除试用版外48小时内可退。搬瓦工30天退款，已消耗较多流量的账号可能扣费。

**DMIT的T1是CN2 GIA吗？**

不是。T1不带中国优化，36.90美元/年买的是香港普通线路。要CN2 GIA，看Pro；要便宜且能接受回程不优化，才看T1。

**Pro和EB差在哪？**

Pro用Premium路由，洛杉矶双向CN2 GIA，联通Premium和CMIN2只走接入方向；EB用Eyeball路由，洛杉矶CN2 GIA只走接入方向，联通和CMIN2双向。要双向GIA选Pro，EB适合回程要求没那么高的场景。

**流量跑完会怎样？**

洛杉矶Pro和EB限速，MINI限到8Mbps；香港和东京暂停到月度重置。付费重置约一个月月费。

**能用来搭VPN吗？**

AUP允许加密私有代理，禁止搭建到中国的VPN隧道，OpenVPN、L2TP、PPTP、IPSec、Cisco AnyConnect都在禁止列表里。买之前确认自己的用途不踩这条线。
